Telegram Mini App · карта пользовательского пути

Сценарии
и их экраны

Первый запуск: Telegram-вход → базовая комната без ключа → профиль и участие → карточки по одной → мэтчи → отдельная передача контакта. Новый гость входит в ту же комнату без ключа; она остаётся после вечеринки. Ключи только для следующих комнат, их макеты вынесены в варианты.

Материал для обсуждения

Это макеты с вымышленными гостями. Новые экраны продолжают оформление исходного хаба. Варианты ещё не становятся требованиями.

Переключай шаги кнопками рядом с экраном. Кнопки внутри телефона показывают будущий интерфейс.

Записывай замечания к сценарию кнопкой снаружи телефона. Они сохраняются только в этом браузере; для передачи скопируй или скачай текст.
