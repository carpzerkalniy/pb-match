### Карта ситуаций · добавлено 05.10

По прямому запросу пользователя карта стала первым режимом этой страницы. Общий узел «Гость на вечере» связан с восемью этапами, каждый этап — с ситуациями из того же JSON. На карте все 40 ситуаций. Линии обозначают группировку; они не устанавливают обязательный порядок действий и не утверждают спорные варианты. Сверху отдельно показана основная линия пути.

- Наведение мышью открывает небольшой предпросмотр первого экрана. Клик/Enter/касание узла открывает модальное окно с названием, статусом, макетом и шагами.
- Шаги переключаются номерами или кнопками «Назад / Следующий». Условия и результат раскрываются отдельно, открытые решения перечислены под описанием.
- Закрытие — крестик, Esc или клик вне окна. После закрытия фокус возвращается на узел. Кнопка подробного описания переводит в существующий каталог.
- Поиск подсвечивает совпадения, сохраняя структуру карты. Масштаб, «По ширине» и перетаскивание фона доступны на компьютере. На узком экране ветки стоят вертикально и прокручиваются; предпросмотр доступен касанием.
- Последняя выбранная ситуация сохраняется при переключении карты/каталога. Старые прямые ссылки на шаг и storyboard открывают подробный режим, в том числе при переходе без перезагрузки.

Реализация: `apps/miniapp/scenarios/situation-map.js` и `situation-map.css`; подключение — существующие index.html/gallery.js. Бизнес-API и содержимое ТЗ не менялись.

Проверка: все 40 модальных сценариев / 87 шагов отрисованы с правильными типами экрана; проверены предпросмотр после прокрутки, поиск Q03a, масштаб, переходы карта/каталог, восстановление выбранного узла при фильтрах, старые hash-ссылки, Esc/фон/возврат фокуса. Мобильные 390×844 и 320×740 — без горизонтального переполнения, шаги доступны над экраном. JS syntax прошёл, ошибок браузера нет. Снимки просмотрены: `preview/situation-map.jpg`, `situation-modal.jpg`, `situation-hover.jpg`, `situation-mobile-390.jpg`, `situation-mobile-320.jpg`.

### Подробный каталог

1. Выбрать этап пути или найти сценарий по слову/номеру вопроса.
2. Проверить статус: «Подтверждённая основа», «Есть открытые решения», «Вариант для обсуждения». Статус относится к сценарию; детали и оставшиеся вопросы отдельно показаны перед реализацией.
3. Переключать шаги над экраном или кнопками «Назад / Следующий шаг». Текст описывает действие гостя и ответ приложения, телефон показывает соответствующий макет. Кнопки внутри телефона служат частью отрисовки.
4. Переключить «Все экраны», чтобы сравнить весь путь одновременно.
5. Использовать «Скопировать ссылку на сценарий»: hash сохраняет ID, активный шаг и режим. Ссылка действует на этом компьютере, пока работает локальный сервер.

Показаны условия входа в сценарий, запуск, результат, исключения, связанные сценарии, нерешённые вопросы и документальное основание. Поиск не изменяет исходные решения; на странице нет действий согласования.

## Файлы и границы

- `apps/miniapp/scenarios/data/scenarios.json` — описания, статусы и шаги из ТЗ, подготовленные агентом сценариев.
- `apps/miniapp/scenarios/screens.js` и `screens.css` — отрисовка экранов агентом макетов. Экспорт `renderScreen(step, scenario)` возвращает HTML телефона.
- `apps/miniapp/scenarios/index.html`, `gallery.js`, `gallery.css` — каталог и переключение экранов, подготовленные агентом галереи.

Категории, число путей и шагов берутся из JSON. Добавление сценария не требует редактировать каталог. Страница проверяет версию, уникальные ID, статусы, категории и наличие экранов. Текст JSON экранируется; внутренние ссылки разрешены только на существующие ID сценариев. Скрипты, изображения и данные локальны; зависимости npm и бизнес-API не нужны.

Основа оформления телефонов — `apps/miniapp/reference/original-hub.html` и текущая адаптация из `docs/DESIGN.md`. Найденный оригинал содержит только хаб. Остальные виды — новые макеты в его стиле, а не найденные исходные экраны. Данные вымышленные. Неподтверждённые развилки остаются предложениями; до выбора политики контакты в работающем приложении раскрывать запрещено.
