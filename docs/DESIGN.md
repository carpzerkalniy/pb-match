## Что адаптировано под подтверждённый первый релиз

- Хаб начинается с комнаты текущего мероприятия. Из неё открываются карточки гостей.
- Карточки с фото/описанием и экран мгновенной взаимности созданы как продолжение этой дизайн-системы: в найденном файле есть только хаб, эти экраны не были предоставлены.
- Вкладка мэтчей и счётчики в хабе обновляются при взаимном лайке. Контакт остаётся закрытым до уточнения отдельного согласия.
- Профиль — локальный эскиз: фото можно просмотреть через object URL, описание хранится в DOM до обновления. Данные не отправляются и не сохраняются на сервере.
- Постоянный клуб и «Резиденты» из источника не включены: выбран запуск знакомства на мероприятии. Полный исходник сохранён для дальнейшего сравнения.
