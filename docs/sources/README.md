## Ограничения восстановления

Старые разделы Mini App из git-истории design.md не извлечены: доступные инструменты Sancho читают файлы, но не выполняют git. Текущее ТЗ восстановлено из доступных документов и журнала решений. Если понадобится уточнить исчезнувшие детали, следующий шаг — получить экспорт прежней версии design.md из репозитория vault.

Исходный код прод-модуля, актуальная схема базы и настройки развёртывания здесь пока не получены. Статус реализации указан по документам, а не по новому обследованию прод-сервера. Некоторые шапки/разделы источников устарели; записи CHANGELOG от 12–25 сентября важнее августовских обещаний.
